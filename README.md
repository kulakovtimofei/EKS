# EKS — Godot

Аркадная игра про трюки на электросамокате в стиле Y2K (глянец, хром, мягкое свечение): комбо, замедление времени в воздухе, фото-охота прямо во время езды. Площадь живёт: толпа прохожих, курьеры «Хвать», конная полиция, иногда проезжают машины. Батарея садится — ищи прокатный самокат и пересаживайся.
Движок Godot 4.7, GDScript, мобильный рендерер, физика Jolt.

## Запуск
Открой папку в Godot и нажми **F5**. Главная сцена — `scenes/levels/catania_duomo.tscn`: Катания, Пьяцца дель Дуомо (фонтан со слоном, собор Святой Агаты, Палаццо дельи Элефанти, Порта Узеда, рыбный рынок, Этна на горизонте). Тестовая площадка — `scenes/levels/test_park.tscn`.

## Управление
| Клавиша | Действие |
|---|---|
| W / S | газ / тормоз (в мануале — баланс) |
| A / D | руль; в воздухе — вращение (нажми уже в воздухе; отпустишь — самокат сам довернётся к ровной посадке) |
| Пробел | олли: нажал — прыжок, подержи до ~0.35 с — выше |
| J (+W / S / A·D) | трюк в воздухе: комета, обратная петля, пропеллер руля, хвостовой вихрь |
| K | мануал: держит комбо между прыжками |
| Shift (держать) | замедление в воздухе, тратит шкалу фокуса |
| F / ПКМ (держать → отпустить) | видоискатель → снимок |
| E | пересесть на прокатный самокат рядом (нужно притормозить) |
| R | рестарт |

Геймпад тоже поддерживается: A — прыжок, X — трюк, Y — мануал, RB — замедление, LB — фото.

## Приземление
В воздухе внизу экрана горит подсказка: «ПРИЗЕМЛЕНИЕ ✓» — садишься чисто, «ДОКРУТИ! ✗» — упадёшь. Трюк, выполненный на 65%, докручивается сам. Падение — только если трюк едва начат или самокат стоит поперёк.

## Как устроено
```
scripts/
  autoload/game.gd      глобальное: ввод, комбо, счёт, фокус, time_scale
  player/scooter.gd     езда, прыжки, трюки, мануал, падения
  camera/chase_camera.gd камера за спиной + зум для фото
  photo/photo_mode.gd   фото-режим: оценка кадра и сохранение PNG
  photo/photo_target.gd метка «это стоит сфотографировать»
  player/rider_model.gd модель райдера и самоката
  pickup/scooter_pickup.gd прокатный самокат: заряд, пересадка
  npc/walker.gd         прохожие, курьеры, конная полиция
  npc/car.gd            машины через площадь
  npc/city_life.gd      спавн толпы, машин, сервис самокатов
  npc/npc_models.gd     модели NPC
  fx/psx.gd             Y2K-материалы: глянцевый пластик, хром, перламутр
  fx/shapes.gd          обтекаемые формы (капсулы, эллипсоиды) для персонажей
  fx/tex.gd             процедурные текстуры
  ui/hud.gd             интерфейс и эффект замедления
  level/catania_duomo.gd карта Катании: застройка, дороги, шиканы, тротуары
  level/build.gd        строительные блоки: дома, фонари, блоки, балюстрады
  npc/nav_graph.gd      граф тротуаров и дорог
  fx/tex_catania.gd     текстуры Катании
  level/test_park.gd    тестовая площадка (собирается кодом)
shaders/slowmo.gdshader пост-эффект замедления
scenes/levels/          сцены уровней
```
Снимки сохраняются в `user://photos/` (`%APPDATA%\Godot\app_userdata\EKS\photos`).

## Тесты
```
godot --headless --path . res://tests/ride_test.tscn
```
Проверяет езду, олли, трюки, замедление, батарею, пересадку, столкновения и машины.
```
godot --headless --path . res://tests/city_test.tscn
```
Проверяет город: машины медленно проходят шиканы и не задевают блоки, курьеры объезжают людей, прохожие держатся тротуаров.
Скриншоты: `godot --path . res://tests/screenshot.tscn -- out.png cathedral` (ракурсы: start, cathedral, fountain, uzeda, etnea, market).
