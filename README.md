# EKS — Euro Kick Scooter (EUROKICK)

Браузерная 3D-игра: катаешься на самокате по старым улицам европейских городов, прыгаешь с трамплинов, крутишь трюки и собираешь монеты. Визуал в духе игр начала 2000-х: низкое разрешение, «дрожащие» вершины, пиксельные текстуры, зерно и приглушённые цвета.

## Что есть

- **4 города:** Прага, Амстердам, Лиссабон, Котор. У каждого своя палитра, фасады (кирпич, азулежу, камень), вывески и черепица.
- **Трюки:** вращение 360/720 (A/D в воздухе), tailwhip (Shift), комбо вроде `360 Double Tailwhip`. Если приземлиться криво, будет падение.
- **Прохожие** гуляют по тротуарам. Если в них въехать, теряешь скорость.
- **Ларёк** на центральной площади каждого города: шмотки (очки, кепка, бини, наушники, полосатые рукава, неоновые колёса, золотая дека), апгрейды (турбо, пружина, магнит) и билеты в другие города.
- **Сохранение** прогресса в `localStorage`.
- **Управление** с клавиатуры и сенсорными кнопками на телефоне.

## Управление

| Действие | Клавиши |
|---|---|
| Газ / тормоз | `W` / `S` или ↑ / ↓ |
| Поворот | `A` / `D` или ← / → |
| Прыжок | `Пробел` |
| Вращение в воздухе | `A` / `D` |
| Tailwhip | `Shift` или `Q` |
| Магазин (у ларька) | `E` |

## Разработка

Нужен Node.js 20+.

```bash
npm install
npm run dev        # дев-сервер на http://localhost:5173
npm test           # юнит-тесты физики и сохранений
npm run build      # проверка типов + сборка в dist/
```

## Структура

```
src/
  main.ts            игровой цикл, камера, связка всего
  physics.ts         чистая логика: движение, трамплины, столкновения, оценка трюков
  save.ts            сохранения, покупки, экипировка
  data.ts            города и товары
  input.ts           клавиатура и тач
  audio.ts           синтезированные звуки (WebAudio)
  render/psx.ts      «приставочные» материалы: снап вершин, текстуры с зерном
  render/post.ts     пост-обработка: цветокоррекция, дизеринг, зерно, виньетка
  world/city.ts      генерация города: кварталы, площадь, ларёк, трамплины, монеты
  world/player.ts    модель райдера и самоката
  world/pedestrians.ts прохожие
  ui/                магазин и спидометр
tests/               vitest
```

Логика в `physics.ts` и `save.ts` не зависит от three.js и DOM, поэтому покрыта тестами.

## Деплой

Workflow `.github/workflows/deploy.yml` собирает игру и публикует её на GitHub Pages при каждом пуше в `main`. Pages нужно один раз включить: **Settings → Pages → Source: GitHub Actions**.
